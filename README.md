# Монахи

Статический многостраничный сайт: `index.html` (главная), по одному файлу `.html` на каждую тему, `style.css`, `main.js` и папка `images`.

## Как выложить на GitHub Pages
1. Создайте репозиторий и загрузите в него ВСЁ содержимое этой папки.
2. Settings → Pages → Source: *Deploy from a branch* → ветка `main`, папка `/ (root)`.
3. Через минуту сайт откроется по адресу `https://ваш-логин.github.io/название-репозитория/`.

Текст каждой страницы можно править прямо в её `.html` файле.
